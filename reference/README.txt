FRAME Console 0.4

실행
index.html을 Chrome 또는 Edge에서 여세요. assets 폴더를 같은 위치에 두면 Pretendard가 로컬에서 로드됩니다. 폰트와 아이콘을 포함해 실행 중 외부 서버에 접근하지 않습니다.

화면 구성
Pretendard의 입력값은 15px, 라벨은 14px로 조정하고 주요 텍스트의 대비를 높였습니다. 송출 시작과 연결 동작은 상단에 고정합니다. 처음에는 창 선택을 안내하고 선택한 소스가 있어야 송출할 수 있습니다. 이벤트 기록과 고급 설정은 접어서 표시합니다. 화면의 불릿과 데모 표시는 넣지 않았습니다.

확인 순서
공유할 창을 선택한 뒤 상단의 송출 시작을 누르세요. 시청하기를 누르면 수신 화면에 바로 연결됩니다. 영상 아래에서 일시정지, 넓게 보기, 전체 화면을 사용할 수 있습니다. 플레이어에 포커스가 있으면 Space 또는 K로 재생을 전환하고 T로 보기 모드, F로 전체 화면을 전환합니다. 주소 오류는 입력칸 아래에 표시하며 송출 종료와 연결 실패 화면에서 다시 연결할 수 있습니다.

구현 상태
UI와 사용자 흐름을 검토하는 프로토타입입니다. 화면은 자체 생성한 패턴과 문서이며, 상태 수치는 화면 동작 확인용입니다. 실제 윈도우 캡처, FFmpeg, MediaMTX, 네트워크 전송은 아직 연결하지 않았습니다. 입력한 주소로 요청을 보내지 않습니다. 상태는 같은 페이지에서만 유지되며 새로고침하면 초기화됩니다.

폰트
Pretendard Variable 1.3.9의 공식 배포 파일을 변경 없이 포함했습니다. assets/fonts/OFL.txt에 저작권 표시와 SIL Open Font License 1.1 원문을 동봉했습니다. 출처와 파일 해시는 assets/fonts/SOURCE.txt에 기록했습니다. 실제 조직의 반입 승인을 의미하지 않습니다.

기본 컴포넌트
입력 포커스는 테두리에 바로 붙는 안쪽 강조선으로 표시합니다. 화질, 프레임, 오디오 선택은 같은 스타일의 자체 메뉴를 사용합니다. 방향키로 이동하고 Enter 또는 Tab으로 적용하며 Esc로 취소합니다. 메뉴 밖을 누르면 닫힙니다.

화질과 프레임
화질은 240p, 360p, 480p, 720p, 1080p, 1440p, 2160p 중 선택하며 기본값은 1080p입니다. 프레임은 기본 60fps이고 30, 60, 90, 120, 144, 165fps 프리셋 및 30~165 범위의 정수 직접 입력을 제공합니다. 이 값은 송출 목표 설정이며 실제 144fps나 165fps 캡처, 인코딩, 전송 성능을 검증한 결과가 아닙니다. 패턴 미리보기는 브라우저에서 최대 60fps로 그립니다.

비트레이트
고급 설정에서 자동 계산과 직접 입력을 전환합니다. 자동 값은 선택한 화질과 프레임에 따라 계산하는 UI 기본값이며 네트워크 상태를 측정하거나 실제 인코더를 최적화하는 기능이 아닙니다.

오디오
사용 안 함, 시스템 소리, 마이크, 시스템과 마이크 혼합을 선택할 수 있습니다. 시스템과 마이크의 음량 및 음소거는 각각 조절하며 송출 상태에서도 조절 가능합니다. 수신 플레이어의 재생 음량은 송출 음량과 분리되어 있습니다. 현재는 UI 상태에 연결되어 있으며 실제 장치 캡처, 음성 믹싱, 오디오 재생은 연결하지 않았습니다.

재생 화질
플레이어 설정 메뉴에서 자동 또는 원본 이하의 화질을 선택할 수 있습니다. 이 프로토타입은 선택한 크기로 캔버스 화면을 조정하는 방식이며 서버가 여러 화질을 인코딩하거나 전송하는 기능은 아닙니다. 실제 다중 화질 송출에는 별도의 인코딩 및 스트림 구성이 필요합니다.
