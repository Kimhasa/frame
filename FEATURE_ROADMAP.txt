사용자가 정한 방향

최우선은 동시 시청 부하 검증, 네트워크에 따른 자동 재생 화질, 모바일 시청 대응이다. 한 방송에서 영상과 음성을 보는 동시 시청자 최대 1,000명을 최종 목표로 둔다. 실제 수용 가능 인원이나 무료 운영 보장을 뜻하지 않는다. 별도 프로그램 없이 인터넷 브라우저로 접속하는 방향이며, 폐쇄 내부망 전용 요구는 더 이상 적용하지 않는다. 기존 로컬 접속·수동 IP/포트 기능을 불필요하게 삭제할 필요는 없다.

전체 목록은 14개 분류, 150개 항목이다. 이는 현재 제품과 비교 플랫폼을 기준으로 만든 관리 가능한 초기 목록이며 이후 발견한 요구는 ID를 보존하며 추가한다. FEATURE_BACKLOG.csv에는 항목별 상태·우선순위·선행 조건·완료 기준이 있다.

현재 상태의 의미

구현: 코드에 기능이 존재한다. 모든 장비·인터넷·1000명 검증 완료라는 뜻은 아니다.
부분: 기초 구현 또는 제한된 범위만 있다.
미검증: 관련 구현은 있지만 해당 장비·규모·환경의 검증이 충분하지 않다.
없음: 현재 검토한 제품 코드에서 해당 기능이 확인되지 않는다.
이번 문서 작업에서 실제 부하·네트워크·모바일 시험은 새로 수행하지 않았다.

우선순위

P0: 이번 구현·검증 58개. 모두 새 기능이라는 뜻은 아니다. 시청 품질 3대 과제와 그에 필요한 관측·인터넷 접속·최소 인증·기존 플레이어 회귀를 포함한다.
P1: 안정화 다음 단계 36개. 계정·채널·운영 도구와 송출 호환성을 보강한다.
P2: 플랫폼 확장 46개. 다시보기·클립·소셜/커뮤니티 확장·후원·참여 기능을 추가한다.
P3: 후기 선택 확장 10개. 유료 미션·선물·광고·추천·추가 기기 등을 제품 방향과 예산에 맞춰 선택한다.

상태 합계: 구현 16개, 부분 43개, 미검증 11개, 없음 80개.

실행 순서

A. 현 코드의 1명 기준을 측정하고 세션·프레임·지연·서버/발생기 자원 관측을 먼저 만든다.
B. 인터넷 경로와 재생 방식, 화질 공유·코덱·모바일 호환 구조를 결정한다.
C. 자동 화질·모바일·환경 문구 제거를 구현하고 기존 UI/캡처/오디오/DVR/채팅을 회귀 검증한다.
D. 개선 전후 같은 조건으로 1→10→50→100→300→500→1,000명까지 단계 검증한다. 지원 장비·트래픽 한도가 부족한 단계는 미검증으로 남긴다.
E. 이번 P0가 안정화된 다음 계정·채널·채팅 운영을 추가하고 후원/유료 기능은 거래 기반이 준비된 뒤 진행한다.
목록의 P1~P3 전부를 이번 실행에서 구현하라는 요청은 아니다. 실제 구현 지시는 CLAUDE_PHASE1_INSTRUCTIONS.txt를 따른다.

현재 코드의 중요한 제약

HTTP 연결 상한 400, 채팅 연결 상한 300이 있다. 이는 검증된 최대 시청 인원과 다르다. 현재의 연결당 스레드 구조·영상 전송량·메모리·인코더와 함께 검토해야 한다.
화질 auto는 현재 원본을 고르는 방식이다. ABR은 시청자별 네트워크와 재생 상태에 따라 실제 다른 화질 스트림을 선택하는 기능으로 새로 구현해야 한다. 송출 목표 비트레이트 자동 계산과 혼동하지 않는다.
HLS는 비활성화되어 있고 하위 화질은 요청 때 인코더가 시작된다. 모바일 Safari·화질 전환·1000명에 맞는 방식은 구현과 검증이 필요하다.
DVR는 현재 방송 중 되감기와 로컬 녹화다. 방송 종료 후 웹 다시보기·클립 서비스는 별도 항목이다.

1,000명 목표와 비용

8Mbps 원본을 1,000명에게 각각 전송하면 영상 데이터만 약 8Gbps, 1시간 약 3.6TB다. 오버헤드·TURN·서버 간 복제는 별도이며 혼합 화질이면 평균이 달라진다. 프레임·해상도·화질 스트림 공유·미디어 배포 구조를 함께 설계한다.
무료 MVP를 원하므로 유료 자원을 임의로 만들지 않고 시험 시간·최대 전송량·무료 한도를 명시한다. API 동접이나 가상 탭 수만으로 실제 영상 1000명 통과를 주장하지 않는다.

UI와 문구 변경

기존 데스크톱 UI는 유지한다. 허용 변경은 모바일 반응형·터치, 실제 자동 화질 표시, 사용자가 요청한 ‘내부망’ 환경 표시 제거와 기능 연결에 필요한 최소 상태다.
work/console-template.html의 environment 배지와 빌드 결과의 같은 문구를 Claude가 정리한다. 오래된 활성 문서의 폐쇄 환경 필수 전제도 갱신한다. 현재 문서 작업에서는 UI 소스·HTML·C++를 수정하지 않았다.
reference/·reference-v05/와 기존 UI 잠금은 보존한다. 새 허용 차이는 새 기준과 데스크톱/모바일 화면 비교로 기록한다.
