1. 하단 플레이어 컨트롤 자동 숨김

재생바, 재생 시간, 일시정지/재생, 음소거·음량, 실시간 복귀, 화질, PiP, 확대 보기와 전체 화면을 포함한 하단 컨트롤 영역을 재생 중 상시 표시하지 마. 하단 그라데이션도 함께 숨겨줘.
영상 영역에 마우스를 올리거나 움직이면 표시하고, 영역을 벗어나거나 재생 중 약 2~3초간 움직임이 없으면 자연스럽게 숨겨줘. 나타나고 사라질 때 영상 크기나 레이아웃이 움직이지 않게 해.
컨트롤 위에 포인터가 있거나 재생바·음량을 드래그하는 동안, 화질 메뉴가 열려 있는 동안, 키보드로 컨트롤을 조작하는 동안에는 숨기지 마. 조작이 끝나면 다시 자동 숨김 정책으로 돌아가.
숨겨진 컨트롤이 투명한 상태로 영상 클릭을 가로채지 않게 해. Tab으로 접근하면 컨트롤이 보이고, 기존 단축키와 영상 영역 클릭의 일시정지·이어 보기 동작은 유지해. 버튼·슬라이더 조작이 영상 클릭으로 중복 처리되지 않게 해.
터치 환경에서는 탭으로 컨트롤을 표시할 수 있게 하고, 한 번의 탭이 컨트롤 표시와 재생 전환을 중복 실행하지 않게 해.
일반 보기·확대 보기·전체 화면에서 같은 정책을 적용해. 브라우저가 자체 관리하는 PiP 창의 기본 컨트롤을 프로젝트 CSS로 제어할 수 있다고 가정하지 마. 채팅이나 설정 입력 중인 키보드 조작을 가로채지 마.

2. 프로그램 창의 제목 표시줄·테두리 제외

현재 영상에 캡처 대상 창의 아이콘, 프로그램 이름, 최소화·최대화·닫기 버튼과 테두리가 함께 들어오는 문제가 있어. 프로그램 창 모드에서는 실제 내용인 클라이언트 영역만 미리보기와 송출에 사용하도록 해줘.
사용자가 다시 지적한 부분은 탭이 아니라 캡처 대상 프로그램의 최상단 제목 표시줄이야. 예시에는 왼쪽의 지구본 아이콘과 ‘FRAME 모션 테스트’, 오른쪽의 최소화·최대화·닫기 버튼이 남아 있어. 이 줄 전체가 실제 영상에 들어오지 않아야 해. 프로그램 내용에 속한 문서 탭·메뉴·도구 모음을 일괄 삭제하라는 요청은 아니야.
이번 요청은 ‘캡처 대상 창의 제목 표시줄을 영상에서 제외’하는 작업이야. FrameConsole 실행 프로그램 자체를 프레임 없는 창으로 다시 디자인하라는 뜻이 아니야.
현재 캡처 API가 제공하는 프레임 범위와 대상 창의 실제 클라이언트 영역을 먼저 확인해. 실제 좌표·DPI·캡처 크기를 대응시켜 자르고, 상단 30px 같은 고정값이나 화면 해상도별 임의 상수를 사용하지 마.
일반 창·최대화·창 크기 변경·다른 모니터로 이동·100/125/150% 등 서로 다른 배율을 처리해. 창 그림자와 보이지 않는 크기 조절 테두리도 좌표 차이에 포함되는지 검증해.
앱이 자체적으로 그린 상단 UI를 OS 제목 표시줄로 잘못 판단해 내용까지 자르지 마. 지원 범위를 확인하고 실패하면 원인을 알려줘. 다른 창이나 전체 바탕화면으로 임의 전환하지 마.
클라이언트 영역에도 자체 제목 표시줄이 들어가는 앱은 GetClientRect 등의 결과만으로 제외가 끝났다고 판단하지 마. 해당 앱의 제목 표시줄과 실제 콘텐츠 경계를 신뢰할 수 있게 구분할 수 있는지 확인하고, 지원하지 못하면 제한을 명확히 밝혀줘. 모든 앱의 상단을 같은 높이로 잘라서 해결하지 마.
동일한 클라이언트 영역을 미리보기와 실제 인코더 입력에 사용해. 미리보기에서만 가리거나 CSS로 덮어서 제목 표시줄이 안 보이는 것처럼 처리하지 마.
실제로 실행 중인 빌드와 캡처 경로도 확인해. 코드를 수정했더라도 구버전 실행 파일, 다른 캡처 경로 또는 제목 표시줄이 포함된 검토용 이미지가 계속 표시되면 원인을 구분해줘. 검토용 이미지 교체만으로 실제 캡처 문제가 해결됐다고 보고하지 마.
전체 화면/모니터 모드는 선택한 모니터를 그대로 공유하는 기능이므로 프로그램 창 전용 제목 표시줄 제거를 일괄 적용하지 마.

3. 플레이어 바깥 틀 유지와 영상 배치·여백 정리

원본 화면 자체의 여백, 캡처 프레임에 포함된 테두리, 인코딩 과정의 패딩, 플레이어 컨테이너와 영상의 비율 차이, CSS padding/border를 구분해서 원인을 확인해줘. 첨부 화면만 보고 원인이 하나라고 단정하지 마.
사용자가 원하는 방식은 플레이어의 바깥 틀을 유지하고 그 안의 영상만 맞추는 방식이야. 이전 지시의 ‘일반 플레이어 영역도 실제 영상 비율을 반영하도록 조정’은 이 요구로 대체해. 캡처 창 크기·비율, 제목 표시줄 제거 여부, 화질 변경에 따라 플레이어나 채팅 영역의 레이아웃이 갑자기 늘거나 줄지 않게 해.
플레이어 바깥 틀은 현재 화면 배치 기준을 유지해. 앱·브라우저 창 크기 변경, 사용자의 채팅 열기·닫기, 확대 보기·전체 화면 전환에는 기존 반응형 규칙대로 대응해. 모든 장치에서 고정 픽셀 크기를 강제하라는 뜻은 아니야. 컨트롤 표시·숨김도 바깥 틀의 크기를 바꾸면 안 돼.
인코더 출력 화면도 선택한 송출 해상도로 유지해. 예를 들어 1920×1080으로 송출 중이면 캡처 창을 정사각형이나 세로 형태로 바꿔도 출력 해상도를 매번 따라 바꾸지 마. 사용자가 송출 해상도를 바꾼 경우에만 지원 범위와 기존 적용 절차에 따라 출력 설정을 갱신해.
제목 표시줄을 제외한 캡처 내용을 고정 출력 화면 안에서 원본 비율을 유지하며 확대·축소하고 가운데 배치해. 미리보기는 실제 송출과 같은 내용 범위·배치 결과를 보여줘. 별도 저해상도 미리보기를 쓰더라도 비율과 잘림 여부는 같아야 해.
화면 맞춤의 기본값은 전체 내용 보존이야. 영상 요소는 비율을 유지하는 contain 방식에 해당하도록 표시하고, 불필요한 CSS 패딩·테두리·중복 크기 변환을 제거해. 여백을 없애려고 cover나 임의 확대를 적용해 글자·버튼·화면 가장자리를 자르거나, fill 방식으로 좌우·상하를 늘리지 마.
원본과 출력 화면의 비율이 다르면 전체 내용을 보존하기 위해 여백이 필요해. 예를 들어 세로 창을 16:9 출력 화면에 넣으면 좌우 여백이 생길 수 있어. 이 여백과 잘못된 캡처·CSS·패딩 때문에 생긴 여백을 구분해. 같은 비율의 원본과 출력에는 불필요한 띠가 없어야 하고, 인코더와 플레이어가 각각 같은 여백을 중복 추가하지 않게 해.
인코딩된 영상에 이미 포함된 여백은 CSS만 바꿔 원래 콘텐츠로 복원할 수 없어. 캡처 → 출력 화면 배치 → 인코딩 → 미리보기·수신 표시의 각 단계를 확인해서 원인 단계에서 정리해. 바깥 틀 고정·원본 비율 유지·전체 내용 보존·모든 여백 제거를 비율이 다른 모든 경우에 동시에 달성했다고 보고하지 마.
선택한 화질의 의미와 실제 인코더 출력 크기를 일치시켜. 캡처 창 크기가 바뀌면 입력 영역과 화면 배치에 필요한 정보를 갱신하되 출력 규격은 유지해. 코덱의 크기 제약과 1px 경계 문제를 확인하고 실제 FPS를 조용히 낮추지 마.

검증과 완료 조건

컨트롤의 기본 숨김·마우스 이동 표시·유휴 숨김·영역 이탈·슬라이더 드래그·화질 메뉴·키보드 접근·터치 표시를 확인해. 영상 클릭 재생·정지, 채팅 입력과 서로 간섭하지 않아야 해.
프로그램 창의 상단 제목 표시줄과 테두리가 미리보기뿐 아니라 다른 PC의 실제 수신 영상에서도 제외되는지 확인해. 창 가장자리에 글자·버튼·색상 표식을 둔 장면으로 내용이 잘리지 않았는지 비교해.
제목 표시줄의 아이콘·프로그램 이름·창 제어 버튼이 모두 빠진 결과를 캡처 원본과 비교해서 보여줘. 테스트 앱을 작게·크게·최대화하고 이동해도 제외 범위가 따라가야 해. 미리보기만 수정한 결과와 실제 송출 결과를 혼동하지 마.
여러 DPI, 창 모드/최대화, 크기 변경, 모니터 이동과 프로그램 창/전체 화면 전환을 확인해. 미리보기·실제 송출·수신 영상의 내용 범위와 비율을 비교해.
가로·정사각형·세로 캡처 창으로 바꿔도 플레이어의 바깥 틀과 인코더 출력 규격이 유지되는지 확인해. 원본 비율과 전체 내용 보존, 필요한 여백, 불필요한 중복 여백 제거를 각각 검증해. 채팅 전환·확대 보기·전체 화면·화질 변경 시에도 영상 비율이 왜곡되지 않아야 해.
기존 reference/와 UI 기준은 보존해. 이번에 요청한 변경으로 기존 스타일 검사가 달라지면 허용된 차이를 기록하고 새 수정 기준과 화면 비교로 검증해. 원본이나 해시를 임의로 덮어써 ‘변경 없음’으로 처리하지 마.
실제 실행 화면과 검증한 환경을 보고하고, 다른 PC나 특정 배율을 테스트하지 못했다면 미검증으로 구분해. 현재 UI와 기존 기능을 보존하면서 구현·빌드·검증까지 진행해줘.
