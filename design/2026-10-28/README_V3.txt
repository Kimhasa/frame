FRAME 디자인 시안 v3 · 2026-10-29

밝은 테마와 정돈된 탐색 흐름을 기준으로 홈, 로그인, 내 설정, 채널 관리, 방송 준비, 방송 중 화면을 구체화한 독립 디자인 시안입니다. 실제 앱에 반영한 버전은 아닙니다.

시작하기
http://127.0.0.1:5328/board-v3.html
http://127.0.0.1:5328/?screen=live

로그인: /?screen=login
내 설정: /?screen=profile
채널 관리: /?screen=channel-edit
방송 준비: /?screen=studio&state=방송%20전
방송 중: /?screen=studio&state=방송%20중

서버가 꺼져 있으면 이 폴더에서 node serve.mjs를 실행합니다. 5328 포트는 로컬 디자인 검토용이며, 다른 PC에 제공하는 실제 시청 주소가 아닙니다.

이번에 달라진 부분
홈의 카드 너비·간격·정보 높이를 정렬하고 헤더 검색과 프로필 메뉴를 정리했습니다. 홈의 직접 연결 버튼을 제거했습니다.
로그인에서 계정 진입, 내 설정에서 프로필·계정 연결·보안 및 기기·알림·재생, 채널 관리에서 기본 정보·브랜딩·권한을 확인할 수 있습니다.
방송 준비와 방송 중 화면에서 영상 아래로 방송 정보와 공유 동작을 모으고, 채팅 접기는 채팅 상단에서 조작하도록 배치했습니다.
FPS·비트레이트 같은 시스템 수치는 기본 화면에서 숨기고 ‘방송 상태’에서 확인하도록 분리했습니다.
선택 메뉴·포커스·입력창을 정돈하고 숫자 입력의 화살표와 textarea 크기 조절 손잡이를 정리했습니다. 후원 금액은 쉼표·원 단위·직접 입력·검증 상태를 갖췄습니다.

검토 방법
프로필 메뉴 → 내 설정/내 채널/채널 관리, 방송하기 → 화면 선택 → 방송 준비 → 방송 중의 흐름을 눌러보세요. 저장·취소·입력 오류, 채팅 접기, 프로필·배너 변경을 함께 확인할 수 있습니다.
계정·방송 정보·후원 입력값은 이 페이지의 로컬 시안 상태입니다. 서버 저장, 실제 OAuth 로그인, 결제, 방송 시작이나 종료를 실행하지 않습니다. 새로고침하면 초기 예시로 돌아갈 수 있습니다.
화면 폭 390·820·1440px 및 넓은 데스크톱 배치를 검토 대상으로 둡니다. 검토 자료는 verification/v3/에 구분합니다.

유지한 범위
기존 영상 플레이어와 화질 제어, 원본 영상 처리 경로는 이번 재설계 대상에서 제외했습니다. 실제 work/·native/·server/ 등 앱 소스, 인증·결제·송출 기능도 수정하지 않았습니다.
PLAYER_PRESERVATION.json의 8개 파일은 원본 참고 자료의 비교 범위입니다. 이 8개 해시만으로 현재 실제 앱 전체를 검증했다고 해석하면 안 됩니다. 원본 reference/·preserved-player/·기존 해시를 새 시안으로 덮어쓰지 않습니다.
기존 58개 화면과 150개 기능 ID의 매핑을 유지했습니다. 모든 화면·세부 정책·실제 기능을 상세 완성했다는 의미는 아닙니다.
