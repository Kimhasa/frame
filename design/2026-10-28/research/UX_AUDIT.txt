FRAME UX 레퍼런스 조사 · 2026-10-28

범위
치지직·YouTube Live·SOOP·Twitch의 공개 목록, 시청 상세, 채널, 검색을 실제 브라우저로 확인하고 18장을 저장했다. 로그인·구매·후원·게시·팔로우는 수행하지 않았다. 캡처는 해당 시점의 화면이며 지역·로그인 상태·뷰포트·방송 상태에 따라 달라진다. 비공개 크리에이터 대시보드와 실제 결제 완료 여정은 조사하지 않았다.

결론
우리 시안은 기능 화면 수보다 탐색 경로, 콘텐츠 위계, 역할 구분, 행동 뒤 복귀 규칙이 부족했다. 밝은 테마를 유지하고 영상 중심의 목록·공개 채널·검색을 먼저 재구성한다. 기존 플레이어·타임라인·음량·화질 메뉴·PiP·전체 화면은 유지한다.

관찰한 흐름
치지직: 목록 → 시청 / 프로필 → 채널 / 검색 → 채널·라이브·동영상
관찰: 채널 콘텐츠 탭과 참여 동작의 구분을 참고. 시청 진입에서 확장 프로그램 안내가 나타났고 설치 없는 시청을 선택했다. 미디어 오류가 나타난 시점이 있어 재생 안정성을 검증했다고 볼 수 없다.

YouTube Live: 라이브 허브 → 시청 → 채널 / 검색 → 결과 유형·필터
관찰: 검색의 위치와 제목·채널·행동의 위계를 참고. 사용자가 선택한 밝은 테마에 해당 위계를 적용한다. Chrome 공개 페이지에서 확인했으며 개인 계정 메뉴·보관함은 열지 않았다. 로그인 상태에 따라 화면이 달라질 수 있다.

SOOP: 전체 LIVE → 시청 / 프로필 → 방송국 / 통합 검색
관찰: 밝은 테마와 검색·목록·시청·채널의 연속성을 참고. 프로모션 팝업은 닫고 캡처했다. 후원·채팅 주변의 많은 아이콘과 팬 순위는 그대로 복제하지 않는다.

Twitch: 탐색 → 생방송 / 채널 동영상·정보 / 검색
관찰: 언어·태그·정렬과 팔로우/유료 정기구독 구분을 참고. 한국 운영 종료 안내가 보이는 공개 화면으로, 국내 서비스 적합성이나 결제 가능 여부를 확인한 것은 아니다.

시안에서 확인된 차이와 조치
[우선] 방송과 채널의 클릭 경로
문제: 기존 카드는 전체가 시청 버튼이라 채널을 찾기 어려웠음
조치: 썸네일·제목은 시청, 아바타·이름은 채널. 두 경로를 분리
현재 범위: 새 시안 반영

[우선] 콘텐츠 정보의 위계
문제: 시스템·기능 설명과 검토 도구가 콘텐츠보다 먼저 보였음
조치: 큰 썸네일 → 제목 → 채널 → 분류. 검토 도구는 따로 열기
현재 범위: 새 시안 반영

[우선] 검색 결과와 재탐색
문제: 검색어가 유지되지 않고 동일한 목록을 다시 표시했음
조치: 검색어 유지, 라이브/채널/다시보기/클립 분류, 결과 없음 복구
현재 범위: 로컬 동작 반영

[우선] 시청자와 방송자 역할
문제: 공개 채널에서 방송 일정 관리 화면으로 이어졌음
조치: 시청자용 일정·알림과 방송자용 예약 관리를 구분
현재 범위: 새 시안 반영

[우선] 시청 연속성
문제: 로그인·후원·채널 전환 뒤 복귀 규칙이 부족함
조치: 돌아갈 방송·재생 위치·음량·채팅 초안을 보존하는 규칙 명시
현재 범위: 기능 작업 필요

[우선] 모바일 시청
문제: 폭만 줄인 표·폼이 남아 있음
조치: 탐색은 한 열, 시청은 영상 우선, 채팅과 입력 영역 검토
현재 범위: 핵심 화면 검토

[다음] 채널의 정체성
문제: 제목과 관리용 입력 중심이라 방송자를 알기 어려움
조치: 배너·프로필·소개·홈/다시보기/클립/일정/정보를 한 맥락에 배치
현재 범위: 공개 채널 반영

[다음] 로그인과 참여
문제: 회원·비회원 경계, 참여 실패 후 복귀가 미정
조치: 시청은 먼저, 채팅·팔로우·후원은 해당 동작에서 필요한 로그인 안내
현재 범위: 상세 정책 필요

[다음] 빈 상태와 실패 복구
문제: 화면마다 안내·다음 행동의 일관성이 약함
조치: 없음/불러오는 중/연결 실패/방송 종료를 구분하고 다시 시도·둘러보기 제공
현재 범위: 핵심 상태 존재

[후속] 후원·멤버십·미션
문제: 기능 이름과 입력 폼 수준, 결제 전체 여정은 미정
조치: 금액·수수료·공개 범위·성공/취소/실패·환불·방송 복귀 설계
현재 범위: 기본 구조 유지

[후속] 채팅 운영과 접근성
문제: 초점 이동·키보드·확대·차단 복구 전체 규칙은 미정
조치: 접근 가능한 이름·초점 복귀·오류 연계·모더레이션 상태 정의
현재 범위: 부분 확인

[별도 검증] 1000명·자동 화질·실제 모바일 재생
문제: 디자인만으로 수용 인원·ABR·호환성을 판단할 수 없음
조치: 부하 시험, 다중 화질 인코딩·전송, 실제 기기에서 검증
현재 범위: 기능·인프라 과제

디자인 우선순위와 기능 우선순위는 별개다. 동시 시청 1000명, 네트워크 기반 자동 화질, 실제 모바일 대응의 기존 기능 우선순위를 낮추지 않는다. 이 조사로 현재 앱의 미구현 기능 전체를 단정하지 않는다. 여기서 확인한 차이는 디자인 프로토타입의 경로와 화면을 기준으로 한다.

가져오지 않을 요소
광고 팝업, 과밀한 태그·배지, 팬 순위, 불필요한 수익화 진입점, 서비스별 전용 용어를 그대로 복제하지 않는다. 치지직에서 탐색 중 유지되는 미니 플레이어를 관찰했으나 기존 영상 제어 유지 지시가 있으므로 이번 변경에는 넣지 않는다. 인페이지 미니 플레이어와 브라우저 PiP는 구분한다.

용어
방송하기 / 방송 시작 / 방송 종료 / 방송 설정 / 공유할 화면 / 라이브 / 채널 / 다시보기 / 클립 / 채팅 / 닉네임 / 방송 링크 / 팔로우 / 멤버십 / 후원하기. 팔로우는 무료 관심 채널 등록, 멤버십은 유료 가입으로 구분한다. 기존 동작을 보존하는 플레이어의 원본 라벨은 예외다.

검증 한계
캡처는 UX 비교 자료이며 성능·영상 품질·재생 호환성 검증이 아니다. 치지직·Twitch 일부 진입에서 미디어 오류, YouTube IAB 로딩 문제가 관찰되어 공개 화면과 Chrome을 함께 사용했다. 실제 방송 소스나 사이트 동작을 수정하지 않았다. 기능 시안의 값·통계·후원 금액은 예시다.
