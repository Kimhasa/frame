FRAME 제품 용어 기준 v2
수정일: 2026-10-29

콘텐츠 메타데이터: 조회수 1,284회 · 2일 전. 라이브 현재 인원은 시청자 수, 관계 등록 수는 팔로워 수로 구분한다. 목록 메타데이터 사이의 가운데점은 항목 구분이며 설명 불릿 목록과 구분한다. 집계 단위의 축약은 별도 규칙으로 관리한다.

적용 대상: 새 화면 문구, 버튼, 모달, 툴팁, 접근성 이름, 오류 메시지. 기존 영상 플레이어·화질 제어의 문구와 모양은 최신 사용자 지시에 따라 유지하며 아래 통일 표현의 일괄 적용 대상에서 제외한다. 내부 변수·API·프로토콜 이름을 문자열 일괄 치환하지 않는다.

문체: 메뉴는 짧은 명사 또는 방송하기. 동작은 시작·종료·선택·저장·취소. 오류는 짧은 해요체, 복구 동작은 명확한 버튼. 같은 대상을 방송/스트림/영상으로 임의 교체하지 않는다. 방송 제목, 스트림 ID, 방송 링크는 각각 다른 값이다.

버튼과 상태 구분

누를 수 있는 실행 버튼은 클릭 후 일어날 동작을 표시한다.
팔로우하지 않음 → 팔로우 / 팔로우한 상태 → 팔로우 취소
방송 알림 꺼짐 → 알림 받기 / 방송 알림 켜짐 → 알림 취소
메시지 고정 전 → 메시지 고정 / 메시지 고정 후 → 고정 해제
기기 연결 전 → 연결 / 연결 후 → 연결 해제
읽지 않은 알림 일괄 처리 → 모두 읽기
예약된 방송 취소 → 예약 취소 (방송 종료와 구분)
채널 관리자·채팅 운영자 권한 제거 → 권한 해제
제한된 사용자의 채팅 복귀 → 참여 제한 해제

실행을 확정하는 모달의 주 버튼은 확인 대신 실행 동사를 쓴다.
예: 예약 취소, 권한 해제, 메시지 삭제, 투표 마감, 소스 삭제, 키 발급, 키 폐기.
입력값을 저장하는 동작은 저장, 검토를 끝내는 동작은 검토 완료로 구분한다.
취소는 미적용 입력이나 진행 중 요청을 취소할 때, 닫기는 결과·정보 창을 닫을 때 사용한다.

상태를 보여주는 배지에는 연결됨·고정됨·저장됨·진행 중을 쓸 수 있다.
완료된 버튼을 비활성화하고 저장됨·복사됨으로 잠시 알리는 것도 가능하다.
목적지를 가리키는 메뉴 팔로잉은 유지한다. 메뉴를 팔로우 취소로 바꾸지 않는다.
설정 스위치는 기능명과 켜짐·꺼짐 상태를 유지하며 매번 취소라는 문구로 바꾸지 않는다.
팔로우·방송 알림처럼 동작 이름이 바뀌는 버튼은 일반 버튼으로 제공한다. 이름이 고정된 토글에 사용하는 aria-pressed를 함께 넣지 않는다. 기능명이 고정된 스위치의 aria-checked는 유지한다.
접근성 기준: https://www.w3.org/WAI/ARIA/apg/patterns/button/
이 기준은 현재 v3.3 시안에 반영한다. 기존 영상·화질 제어는 보호 범위이므로 변경하지 않는다.
