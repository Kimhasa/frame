FRAME 디자인 재검토 v2.0 · 2026-10-28

최신 방향
사용자는 밝은 테마, 유튜브처럼 정돈된 구성을 선택했다. 치지직·YouTube Live·SOOP·Twitch를 실제 브라우저로 조사하고 공개 화면 18장과 흐름·차이 12개를 기록했다. 어두운 참고 화면을 밝은 테마로 복제하는 것이 아니라 탐색 경로와 정보 위계를 참고한다.

시안 주소
http://127.0.0.1:5328/board.html : 새 핵심 화면·모바일 배치·전체 화면 연결
http://127.0.0.1:5328/research.html : 실제 캡처·출처·차이 비교표
http://127.0.0.1:5328/index.html?screen=live : 눌러보는 디자인

이번 변경
흰 헤더와 검색, 콘텐츠 중심 카드, 일관된 아바타·제목·분류 위계로 정리했다.
썸네일·방송 제목은 시청으로, 아바타·채널 이름은 공개 채널로 이어진다.
검색어를 유지하고 라이브·채널·다시보기·클립을 구분한다. 로컬 예시 데이터 검색이며 실제 검색 API는 없다.
공개 채널에는 홈·다시보기·클립·방송 일정·정보 탭이 있다. 시청자용 방송 일정을 방송자의 예약 관리 화면과 분리했다.
화면 수·기능 ID·설계 검토 도구는 기본 화면에서 접고 ‘화면 검토’로 열게 했다.
모바일 시청에서는 검토 버튼이 채팅 입력 영역을 가리지 않게 했다.

아직 설계가 더 필요한 부분
로그인이나 후원 뒤 보던 방송으로 돌아가는 규칙, 실제 상태 보존, 세부 결제·환불·정산 정책, 채팅 운영·접근성 전체 검증, 모바일 실제 기기 재생은 남아 있다.
기능 목록 150개·58개 화면의 기존 연결을 유지했다. 모든 화면을 세부 정책까지 완성했다는 의미는 아니다. 기존 분류상 상세 11개·기본 구조 45개·기존 유지 1개·검증 자료 1개다. 공개 채널과 검색은 이번에 추가로 흐름을 상세화했다.

보존 경계
실제 work/·native/·server/ 소스는 수정하지 않았다.
기존 플레이어·화질 메뉴·음량·재생바·PiP·전체 화면·영상 처리 경로는 변경하지 않았다. 디자인 내부의 원본 참고 어댑터를 유지한다.
원본 reference/와 원본 해시는 갱신하지 않았다. v1 캡처는 dist/assets/artboards/에 남아 있고 새 대표 캡처는 verification/v2/와 dist/assets/v2/에 구분했다. archive-v1/은 이전 디자인 소스다.
이 문서는 실제 앱에 시안 전체를 덮어쓰라는 지시가 아니다.

검사에서 가로 스크롤 카테고리·표 내부의 컨트롤은 별도 분류한다. 브라우저 실제 재생·보안·결제·부하 검증은 아니다.
verification/v2/ : 새 핵심 화면과 390px 폭 캡처

실제 기능 우선순위
동시 시청 부하 1000명 목표, 네트워크에 따른 자동 화질, 모바일 대응의 기존 우선순위를 유지한다. 이번 디자인 변경으로 해당 기능을 구현했다고 보고하지 않는다.
