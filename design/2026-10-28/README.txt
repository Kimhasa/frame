시안 수준
상세: 핵심 시청·방송 흐름과 화면 선택·연결·정보·닉네임 등의 상세 시안.
기존 유지: 이미 만든 화질 메뉴. 기존 플레이어 마크업·스타일·아이콘을 읽어 온 어댑터로 보여준다.
기본 구조: 계정·채널·후원·참여·운영 등 후속 기능의 1차 화면과 필드·표·확인 상태. 모든 세부 탭과 정책까지 확정된 완성 디자인은 아니다.
검증 항목: 동시 시청 부하·미디어 전송·인프라처럼 일반 사용자 화면이 필요 없는 기능의 별도 검증 자료.

변경 금지 범위
사용자의 최신 지시에 따라 기존 영상 플레이어, 화질 메뉴, 자동·수동 화질 동작, 음량·음소거, 재생·일시정지, DVR 재생바, 실시간 복귀, PIP·전체 화면·확대 보기, 캡처·인코딩·전송 기능은 재설계하지 않는다.
이 작업은 실제 work/·native/·server/의 앱 소스를 수정하지 않는다. 시안의 플레이어는 실제 영상 대신 화면 예시를 담은 표현 계층이며 새 영상 처리 엔진이 아니다.
preserved-player/에는 기존 UI 소스의 읽기 전용 참고 복사본을 보존했고 PLAYER_PRESERVATION.json에 원본 파일의 SHA256을 기록했다. 원본 reference/·UI 잠금 파일은 덮어쓰지 않았다.

레퍼런스
치지직과 SOOP의 공개 탐색 화면, 사용자가 제공한 치지직·Discord 이미지, YouTube 공식 라이브·채팅·멤버십 안내를 참고했다.
참고 범위는 방송 카드, 탐색·채널 진입, 채팅과 참여 기능, 계정·알림 흐름이다. 각 서비스의 색상·광고·고유 재화·플레이어 제어를 복제하는 작업은 아니다.

데이터와 실제 기능
방송·채팅·통계·가격·계정·앱 아이콘은 검토용 데이터다. 실제 로그인·결제·후원·장치 검색·송출 성공이나 동시 시청 성능을 뜻하지 않는다.
예시 가격, 혜택, 정산 수치, 로그인 제공자는 확정된 운영 정책이 아니다.
부하 1,000명과 모바일 실제 재생 검증은 기존 기능 구현 과제로 유지하며 이 시안의 렌더링 검증과 구분한다.
기존 기능 목록의 현재상태는 작성 당시 스냅샷이며 최신 코드의 구현 상태를 새로 보증하지 않는다.

의존성
외부 패키지 설치 없이 정적 HTML/CSS/JavaScript로 동작한다. Pretendard는 기존 프로젝트에 포함된 폰트와 OFL 라이선스를 함께 복사했다. 외부 폰트 CDN이나 외부 API 호출을 사용하지 않는다.
