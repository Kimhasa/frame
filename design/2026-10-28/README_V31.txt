이번 변경
빈 화면은 테두리 없는 간결한 구성으로 정리했습니다. 검색 결과 없음은 ‘검색어 수정’, 연결 오류는 ‘다시 시도’처럼 상황에 맞는 동작을 제공합니다. 로딩 상태에는 접근성 상태 표시를 적용합니다.
공개 채널·검색 결과·채널 관리의 탭은 투명 배경과 밑줄로 통일했습니다. 키보드 포커스를 유지하며 좁은 화면에서는 탭 안에서 가로로 이동할 수 있습니다. 카테고리 칩과 내 설정의 세로 메뉴는 별도 스타일을 유지합니다.
방송 정보에는 제목·채널·설명·카테고리만 남겼습니다. 공유는 선택한 방송을 기준으로 표시하며 기본 화면에서 임베드 코드를 제거했습니다. 닫으면 원래 화면으로 돌아갑니다. 다시보기와 종료 화면에는 LIVE·실시간 시청자 수를 표시하지 않습니다.
중복 홍보·설명 문구를 줄였습니다. 정책 화면은 개발용 설명 대신 준비 중 상태로 표시하고, 가입자 없음 화면에서는 예시 가입자 수를 함께 보여주지 않습니다.
320px부터 넓은 화면까지 배치를 보완했습니다. 실제 820px 화면과 820px 미리보기의 구성을 맞추고 스튜디오 채팅 높이를 정리했습니다. 홈의 라이브 카드 8개는 화면 폭 때문에 숨기지 않으며, 이어보기 4개는 가로 레일로 제공합니다. 확대 보기 설정이 다른 페이지의 사이드바에 영향을 주던 문제도 정리했습니다.

검토할 흐름
검색 결과 없음 → 검색어 수정, 오류 → 다시 시도, 탭 전환 → 키보드 포커스, 방송 정보·공유 → 원래 화면 복귀를 확인하세요. 320·390·820px와 데스크톱에서 홈, 채널, 방송 준비·방송 중을 함께 살펴보세요.
로그인·후원·방송 상태는 로컬 예시 상호작용입니다. 실제 계정 인증, 결제, 방송 시작·종료, 성능 시험 결과가 아닙니다. 기존 영상 플레이어와 화질 제어는 유지합니다.
검증 결과 정리 위치는 verification/v31/입니다. 최종 결과와 미확인 항목을 이곳에 기록하며, 확정 전 검사 횟수나 통과 수를 이 문서에 제시하지 않습니다.

보존과 인계
실제 앱 소스, 원본 플레이어·화질 제어와 미디어 경로는 이번 변경 대상에서 제외했습니다. 기존 58개 화면·150개 기능 ID의 매핑을 유지하지만, 모든 기능과 세부 정책을 상세 완성했다는 뜻은 아닙니다.
