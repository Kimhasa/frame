1. 시안과 실제 구현의 경계

dist/는 독립 HTML/CSS/JavaScript 디자인 검토물이다. 실제 앱, 인증, 결제, 송출 기능을 수정하거나 서버에 배포한 결과가 아니다. 이 문서만으로 실제 앱 전체 반영이나 기존 P1~P3 기능 일괄 구현이 승인됐다고 가정하지 마. 사용자가 반영하기로 한 UI 범위에서 기존 앱에 필요한 부분을 연결해.

밝은 테마·Pretendard·절제된 녹색을 유지해. 레퍼런스는 치지직·YouTube Live·SOOP·Twitch의 탐색과 정보 위계이며 해당 사이트의 브랜드나 어두운 테마를 복제하는 작업이 아니다. 계정 조사 근거는 research/account-2026-10-29/ACCOUNT_CREATOR_UX_AUDIT.txt를 확인해. 치지직·SOOP·Twitch의 공식 가이드 확인을 실제 로그인 화면 관찰로 보고하지 마.

2. 이번에 구체화한 UI 범위

홈: 카드의 열·간격·썸네일 비율·제목 영역을 맞춘 반응형 그리드, 헤더 검색, 카테고리·정렬, 프로필 메뉴. 홈의 ‘직접 연결’ 진입은 제거한다. 이를 이유로 기존 고급 연결 설정이나 서버 IP·포트 기능 전체를 삭제하지 마.
로그인: 제공자 선택·이메일 입력·오류·계정 확인·이전 목적지 복귀. Google·네이버 표시는 시안용이며 실제 OAuth 요청을 보내지 않는다.
내 설정: 프로필, 계정 연결, 보안 및 기기, 알림, 재생을 분리한다. 여기에 기본 영상 화질 선택을 새로 추가하지 마.
채널 관리: 기본 정보, 브랜딩, 권한과 채널 미리보기. 공개 채널 보기와 관리 화면을 구분하고 역할에 따라 읽기 전용 상태를 제공한다.
방송 준비: 공유 화면 선택, 제목·카테고리·공개 설정·태그, 저장·방송 시작 흐름.
방송 중: 영상, 채팅, 현재 방송 정보, 공유, 필요한 수정과 오류 복구 흐름.

방송 정보와 공유 동작은 영상 아래에서 찾게 한다. 채팅 접기 버튼은 채팅 헤더에 둔다. 기본 채팅 열림을 유지한다. FPS·비트레이트·연결 방식 같은 시스템 수치는 일상 화면에 상시 나열하지 않고 ‘방송 상태’에서 확인하게 한다. 실제 측정값과 목표값은 기능 연결 시 구분해야 한다.

공통 컴포넌트는 기본 브라우저 모양이 튀지 않도록 선택 메뉴·포커스·체크·입력창을 정돈한다. textarea 크기 조절 손잡이와 숫자 spin 버튼을 정리하되 키보드 입력·검증·접근성 이름을 보존한다. 후원 금액은 쉼표, 원 단위, 선택 금액/직접 입력, 최소 금액 오류와 제출 금액이 일치해야 한다. 시안의 예시 금액을 실제 결제 정책으로 확정하지 마.

3. 기존 플레이어와 원본 보호

기존 영상 요소, 화질 메뉴의 배치·옵션·자동/수동 동작, 재생·일시정지, 음량·음소거, DVR·실시간 복귀, PiP·전체 화면·확대 보기의 구현을 교체하거나 재디자인하지 마. 영상 바깥 정보 배치 변경과 영상 제어 자체 변경을 구분해. 캡처·크기 변환·인코딩·전송·코덱·비트레이트 계산은 이 디자인 인계의 변경 범위가 아니다.

이 목록은 시안 작업 당시 원본 참고 자료의 해시 기준이다. 현재 실제 앱 전체나 이후 허용된 기능 변경의 검증을 대신하지 않는다. preserved-player/를 최신 앱 위에 덮어쓰거나 사용자에게 승인된 이후 변경을 강제로 되돌리지 마. reference/·reference-v05/·원본 해시를 갱신해 ‘변경 없음’으로 처리하지 마. 실제 앱 소스는 이번 v3 디자인 작업의 수정 대상에서 제외했다.

4. 로컬 상호작용을 기능으로 연결할 때

계정 시안은 F.accountDesign에 프로필·채널 초안, 선호 설정, 역할과 멤버 목록을 보관한다. F.sessionLoggedIn과 F.authReturn은 시안 내 계정 전환과 복귀를 위한 상태다. 실제 세션·권한·OAuth 검증을 구현한 것으로 간주하지 마.
방송 정보는 F.studioDraft와 모달 초안을 분리해 저장/취소를 표현한다. 후원은 F.v3DonationDraft의 로컬 금액·메시지·동의 상태를 사용한다. 예시 방송·시청자·활동·기기·연결 계정·후원 완료를 실제 서버 데이터나 실제 거래로 옮기지 마.
실제 연결 시 기존 플레이어와 서비스 구조를 재사용해. 메뉴 이동, 프로필 수정, 채팅 접기, 정보 모달 때문에 video 요소·선택 화질·음량·DVR 위치·방송 세션·채팅 초안이 초기화되지 않게 한다. OAuth와 결제는 서버가 확인한 결과에만 성공 상태를 표시한다.
