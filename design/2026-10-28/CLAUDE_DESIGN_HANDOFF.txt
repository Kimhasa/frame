가장 우선하는 최신 사용자 지시
디자인 레퍼런스는 치지직·YouTube Live·SOOP이야. 탐색·채널·계정·참여 흐름을 참고하되 기존 FRAME 테마와 컴포넌트 스타일을 이어가.
이미 만든 영상 플레이어와 화질 제어는 건드리지 마. 화질 메뉴의 모양·배치·옵션·자동/수동 동작, 재생·일시정지, 음량·음소거, DVR·실시간 복귀, PIP·전체 화면·확대 보기를 재설계하거나 교체하지 마.
영상 제어를 새 프레임워크나 새 video 요소로 갈아끼우지 마. 캡처·크기 변환·인코딩·전송·코덱·비트레이트 계산도 이 디자인 작업에 섞어 변경하지 마. 기존 품질·성능 검증 과제는 별도 지시 범위와 구분해.

시안의 의미
이 패키지는 앱 코드 수정 없는 디자인 검토용이야. 지금 이 문서가 기존 기능 개발 범위를 P1~P3 전체 구현으로 확대하는 지시는 아니야.
후속 구현 시에는 사용자가 반영하기로 한 화면 범위를 기준으로 연결해. 상세·기존 유지·기본 구조·검증 항목을 구분하고 기본 구조 시안이 모든 정책과 세부 탭까지 확정된 완성 명세라고 가정하지 마.
시안은 기존 C++/WebView2/미디어 구조를 바꾸라는 요구가 아니야. React나 Electron 전환도 이 작업에 포함하지 않아.

용어
기본 메뉴는 방송하기·라이브로 통일해. 동작은 방송 시작·방송 종료, 설정은 방송 설정, 입력은 방송 제목, 공유 주소는 방송 링크, 사용자는 방송자·시청자로 표시해.
무료 관심 등록은 팔로우, 유료 정기 가입은 멤버십, 일회성 금액과 메시지는 후원으로 구분해. 서버 주소·포트·스트림 ID·비트레이트·코덱은 정확한 고급 설정 용어로 남겨.
TERMINOLOGY.txt는 기본 화면·새 기능·툴팁·접근성 이름의 기준이야. 이미 구현된 플레이어 제어의 문구와 모양은 최신 유지 지시가 우선하므로 이 표를 이유로 일괄 치환하지 마. 내부 API·변수·프로토콜 이름도 문자열 치환하지 마.

기존 UI 요구 보존
불필요한 대제목·설명 카드·불릿 안내·데모 표시를 추가하지 마.
방송 시작·연결 버튼 옆에 대기·준비됨·송출 중 배지를 붙이지 마.
시청 상세에 좌측 정보 패널, 목록으로·제목·시간의 반복 상단 줄, 연결 설정·수신 종료를 되살리지 마.
기본 채팅 열림, 닉네임 설정, 채팅 글자 수 표시 없음, 시청 상세에서 라이브 메뉴 활성 해제, 확대 보기 동작 때만 좌측 메뉴 축소를 유지해.
공유할 화면 선택창의 폭 확대·2열 썸네일·앱 아이콘·제목 확대는 사용자가 별도로 허용한 변경이야. CLAUDE_WINDOW_PREVIEW_ADDENDUM.txt의 최신 요구를 함께 확인해.

실제 연결 시 지킬 사항
시안의 가짜 방송·채팅·통계·계정·가격을 운영 UI에 넣지 마. dist/는 표현과 동선 참고용이며 실제 서비스 코드 전체로 복사하지 마.
preserved-player/는 원본 참고 복사본이므로 현재 앱의 최신 코드 위에 덮어쓰지 마. PLAYER_PRESERVATION.json은 이 시안 작업 당시의 비교 기준이며 이후 사용자가 허용한 실제 기능 변경을 강제로 되돌리는 잠금이 아니야.
현재 앱의 기존 컴포넌트를 직접 재사용하고 새 페이지와 서버 응답을 필요한 경계에서 연결해. 공통 헤더·메뉴가 플레이어 상태, 선택 화질, 음소거, 재생 위치, 진행 중인 방송과 채팅 초안을 초기화하면 안 돼.
후원·멤버십·미션·정산의 가격·혜택·거래 정책과 로그인 제공자는 후보 표현이야. 실제 인증·결제·권한·서버 검증이 준비되지 않았는데 성공한 것처럼 처리하지 마.
