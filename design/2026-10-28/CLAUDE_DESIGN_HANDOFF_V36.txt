기존 CLAUDE_INSTRUCTIONS.txt와 v3.5 전달 사항을 확인하고 이어서 작업한다.

최신 시안은 dist/index.html, 조사 비교는 dist/broadcaster-review.html이다. 연구 폴더의 manifest는 실제 관찰과 추론, 미확인 범위를 구분한다. 개인 계정·키 관련 원본은 배포물에 넣지 않는다.

유지할 UI

밝은 테마, Pretendard, 현재 카드·모달·아이콘·자체 선택 메뉴·슬라이더·포커스 스타일을 유지한다. 방송 정보 편집과 영상/오디오/녹화 출력을 구분한다. 치지직/Twitch의 외부 송출 구조를 FRAME 자체 캡처 구조에 그대로 강요하지 않는다. 기본 방송 과정에 스트림 키 직접 입력 단계를 추가하지 않는다.

이번 디자인 동작

design-v36-source-flow.js/.css: 선택 목록의 pending 대상과 실제 F.source를 구분한다. 확인에서만 적용한다. 취소·닫기·ESC·이탈은 폐기한다. 방송 중 대상 변경은 적용 전 확인한다. 오류 상태의 시작 차단은 로컬 검토 상태에 근거한다.

design-v36-settings-flow.js: 영상·오디오·녹화의 UI 초안을 저장/취소 단위로 다룬다. 취소 시 값 전체를 복원하고 음량·녹화 선택도 같은 세션에서 유지한다. 연결/방송 설정 모달은 열린 화면으로 돌아간다. 컨트롤 렌더러, 옵션 범위와 미디어 로직을 대체한 변경이 아니다.

design-v36-broadcast-info.js/.css: 방송 정보 초안/저장과 변경 없음/취소/저장 후 방송 카드 반영을 연결한다. 실제 서버 저장과 접근 권한을 구현하지 않는다.

실제 기능 연결 시 요구

캡처 대상의 유효성은 실제 창/모니터 핸들 상태로 확인한다. 목록 선택만으로 송출 대상을 변경하지 않는다. 방송 중 변경 시 지원 여부와 새 대상의 준비를 확인하고 성공 후 한 번에 적용한다. 실패하면 기존 대상을 유지하며 임의 대상 전환을 하지 않는다.

방송 시작 조건은 실제 캡처 준비, 인코더 준비, 송출 연결 확인을 사용한다. 연결 주소의 형식 검사만으로 연결 성공·방송 가능을 표시하지 않는다. 시안의 오류 프리셋은 실제 장치/서버 이벤트와 연결해야 한다.

방송 정보 저장은 서버 응답 이후 성공으로 처리하고 실패 시 초안을 유지한다. 저장된 제목/카테고리와 목록·채널·공유 화면을 같은 데이터로 구성한다. 공개 설정은 서버에서 권한을 검증하며 UI 표시만으로 제한하지 않는다.

출력 설정은 준비 중/방송 중 변경 가능 범위를 실제 인코더 기준으로 구분한다. 재시작이 필요한 값은 변경 전에 알린다. 저장 실패 시 마지막 적용값을 유지하고 초안은 재시도할 수 있어야 한다. 저장·취소 시 네이티브 설정을 이미 적용했다가 되돌리는 방식보다 적용 전 초안 경계를 우선한다.

영상 플레이어, 화질 메뉴, preserved-player/ 및 PLAYER_PRESERVATION.json 기준은 보존한다. 새 컨트롤로 다시 만들거나 기존 해시를 덮어써 변경 없음으로 처리하지 않는다.

실제 채팅은 개인 표시 설정과 전체 채널 운영 규칙을 구분하고 권한을 서버에서 확인한다. 읽는 중 새 메시지가 와도 강제로 맨 아래로 이동하지 않는 기존 UI를 유지한다. 시안의 닉네임 변경·메시지·이름 역할 표시만으로 계정/운영 권한이 구현됐다고 보고하지 않는다.

검증과 보고

UI 검증은 verification/broadcaster-review/에 있고, 실제 송출 검증은 별도다. 창/모니터 변경 취소와 실패 복원, 저장/취소/ESC/뒤로가기, 제목 변경 후 목록 일치, 다른 화면에서 열린 모달 복귀를 실제 앱에서 확인한다. 실제 송출·수신·FPS·네트워크·1000명 부하 검증을 수행하지 않았다면 구현/검증 완료로 보고하지 않는다.
