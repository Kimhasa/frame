확인일: 2026-10-28

치지직
https://chzzk.naver.com/
공개 화면에서 고정된 헤더·검색·사이드바, 전체 방송·팔로잉·클립·방송 일정, 썸네일/방송 제목/채널/분류를 통한 진입 구조를 확인했다. 사용자가 제공한 시청·카드·채팅 이미지도 기준으로 삼았다.
FRAME 적용: 짧은 메뉴, 읽기 쉬운 카드, 목록에서 바로 시청, 채널 이동과 채팅 주변 참여 기능.
가져오지 않는 범위: 어두운 전체 테마로의 전환, 광고·행사 배너, 치즈 등 고유 재화 이름, 기존 플레이어 제어의 교체.

공식 라이브 안내에서 시청·채팅·후원·멤버십·방송 후 다시보기의 관계를, 채팅 검토 안내에서 참여 범위와 운영 도구의 분리를 참고했다. 로그인된 개인 계정의 내부 화면이나 결제 절차를 직접 시험한 것은 아니다.
FRAME 적용: 계정과 채널 중심 탐색, 팔로우/멤버십/후원을 구분한 진입, 채팅 운영과 시청을 분리한 화면 구성.
가져오지 않는 범위: YouTube 고유 명칭·가격·정책, 플레이어·화질 메뉴·지연 설정·인코더 권장값의 교체.

SOOP
https://www.sooplive.com/
공개 탐색 화면에서 검색·알림·로그인, LIVE·탐색·MY·Catch, 채널 프로필과 방송 카드·일정으로 이어지는 구조를 확인했다. 구 도메인의 이동 후 현재 공개 도메인을 참고했다.
FRAME 적용: 시청/개인/방송자 동선을 나누고, 후원·미션·운영 기능은 각 목적에 맞는 위치에 배치.
가져오지 않는 범위: 고유 재화·구독 명칭, 광고·외부 상점 구성, 기존 영상 기능과 UI를 전면 교체하는 작업.

기존 FRAME
Pretendard, 밝은 콘솔 표면, 짙은 헤더, 녹색 강조와 이미 구현된 자체 입력·메뉴·슬라이더 스타일을 기준으로 삼는다.
사용자가 요청한 ‘기존 영상·화질 제어 유지’는 플랫폼 레퍼런스보다 우선한다. 플랫폼별 보이는 요소를 전부 붙이지 않고 현재 기능 목록과 실제 이용 흐름에 필요한 구조만 설계한다.
