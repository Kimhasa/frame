# FRAME 포트폴리오 캡처

실제 구현된 React 화면에 포트폴리오용 가상 데이터를 채운 화면 캡처다. 화면 안에 별도의 소개 문구나 미리보기 배지를 덧붙이지 않았다. 녹색 색감과 기존 레이아웃을 유지했다.

## 파일

- `screens/`: 데스크톱·모바일 PNG 원본. 데스크톱은 1600×1050 CSS 화면을 2배 해상도로 캡처하고, 모바일은 390×844 CSS 화면을 2배 해상도로 캡처한다. 개별 파일의 실제 크기는 `screens/manifest.json`에 있다.
- `index.html`: 이미지 모음. 브라우저에서 개별 원본을 열고 내려받을 수 있다.
- `live-chat-data.json`: 가상 라이브 방송 12개와 채팅 30개.
- `analytics-revenue-data.json`: 방송 통계 30회, 가상 거래 84건과 정산 데이터.
- `image-sources.json`: 추가 썸네일에 사용한 사진의 원본 주소.
- `site/`: 이 데이터를 담아 별도로 빌드한 화면. 서버 연결 없이 작동하는 디자인 전용 번들이다.
- `fixtures/`: 가상 채널 14개(라이브 12개·오프라인 2개), 다시보기·클립·게시글·일정과 다른 데이터가 들어 있는 임시 소스 사본. 원래 앱 소스에 적용하지 않았다.

캡처는 데스크톱 8장(라이브 목록, 시청·채팅, 채널 홈, 팔로잉, 방송 스튜디오, 방송 분석, 수익·정산, 채널 다시보기)과 모바일 3장(라이브 목록, 채널 홈, 시청·채팅)으로 총 11장이다.

로컬 미리보기:

```powershell
node outputs/portfolio-frame/serve.mjs
```

이미지 모음은 `http://127.0.0.1:5362/`, 화면은 `http://127.0.0.1:5362/_frame/live`에서 연다. 스튜디오에 들어갈 때는 기존 디자인용 로그인 화면에서 로그인 버튼을 누르면 된다. 실제 계정이나 비밀번호는 필요 없다.

## 데이터 기준

2026-11-11 20:18 KST를 기준으로 예시 날짜를 고정했다. 방송 제목의 길이, 카테고리와 시청자 수의 편차, 채널 소개·다시보기 길이·짧은 채팅 대화 같은 표현 방식을 공개 서비스에서 참고했다. 실제 채널의 이름·아바타·연락처·채팅을 복사하지 않았다.

참고한 공개 화면과 공식 설명:

- [치지직 홈](https://chzzk.naver.com/): 라이브 제목, 카테고리, 시청자 수, 다시보기와 클립의 표시 형식
- [YouTube 실시간 채팅](https://support.google.com/youtube/answer/2524549?hl=ko): 방송과 함께 대화가 이어지는 채팅 구성
- [YouTube 실시간 스트림 측정항목](https://support.google.com/youtube/answer/2853833?co=GENIE.Platform%3DDesktop&hl=ko-KO): 시청 시간과 동시 시청자 등 지표의 의미

채널·시청자·팔로워·후원·수익·통계 수치는 모두 가상이다. 실제 이용자, 매출, 부하 검사나 서비스 운영 성과를 나타내지 않는다. 분석의 합계·평균은 가상 상세 데이터에서 기존 화면의 계산식으로 집계한다. 수익과 정산 데이터도 예시 기준으로 맞췄다.

## 작업 격리

실제 앱 폴더의 복사본에서 데이터를 바꿔 빌드했다. 원래 `apps/web/src`와 실행 중인 5360번 앱, OBS 수신 서버, 실제 방송·결제 데이터에는 적용하지 않았다. 캡처 시 API·HLS·OBS 서버 요청도 차단했다. 커밋·푸시·배포는 하지 않았다.
